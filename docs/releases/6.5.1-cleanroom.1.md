# Hostile Neural Networks Legacy 6.5.1-cleanroom.1

面向 **Minecraft 1.12.2 / Cleanroom 0.4.0 正式版（无 `-alpha`）/ Java 25** 的首个独立发行版，由 **yudream** 维护。

## 安装

下载 `hostile-neural-networks-legacy-6.5.1-cleanroom.1.jar` 放入客户端和服务器的 `mods/`，更新时替换本项目旧 jar。`-sources.jar` 为开发源码，无需安装；`SHA256SUMS` 可用于校验下载文件。

- 必需：Cleanroom 0.4.0 正式版、Java 25；不需要 Placebo。
- 可选：[Ponder Legacy 1.4.0-cleanroom-alpha.1](https://github.com/mcyudream/ponder-legacy/releases/tag/v1.4.0-cleanroom-alpha.1)（另需 CraftTweaker 4.1.20.698），JEI 4.16.1.302。
- Loader Mod ID：`hostile-neural-networks-legacy`；资源与注册命名空间：`hostilenetworks`。

## 内容

- 深度学习器、模型框架与击杀成长，29 个默认生物模型、8 个可选矿物模型。
- 模拟室训练 / 推理、连续准确率与超过 100% 的多次产出。
- 战利品制造机、固定产物和轮转队列、制造指令卡。
- 7×7×7 数据中心、25 个并行模型、共享库存与四种 IO 端口。
- Forge Energy、自动化、红石、可保存的满仓缓冲和服务端交互校验。
- 可自定义模型 / 等级 JSON、原子重载与客户端同步。
- 与上游对齐的界面、实体预览和 HUD，独立制造设置页、小窗口缩放及 JEI 避让。
- 中英文界面、可选 JEI 配方页和两套 Ponder 演示。

## 验证与范围

正式 Cleanroom **0.4.0** 上，客户端无可选依赖 / 安装 Ponder 与 JEI 两种组合分别通过 **46 / 70** 项检查；专服无 Ponder / 安装 Ponder 两种组合各通过 **38** 项检查。CI 标签发布强制核对生产包与运行验收包的 SHA-256。

1.12 不存在的生物和未核实的第三方模型未声明兼容；部分实体 display 偏移、动画和彩虹颜色尚未完全复现。不提供其他 HNN / Deep Mob Learning 实现的存档转换。具体差异、验收证据与界面截图见仓库 README、LEGACY-VERIFICATION.md 和 docs/UI.md。
