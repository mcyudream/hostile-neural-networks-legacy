# Hostile Neural Networks Legacy 6.5.1-cleanroom.2

适用 **Minecraft 1.12.2 / Cleanroom 0.4.0 正式版（无 `-alpha`）/ Java 25**。

## 新增可选联动

- 龙之研究：混沌守卫模型，制造混沌碎片、龙之心或龙尘；末影龙预测增加龙之心选项。
- 热力基本：Blizz、Blitz、Basalz 模型，制造对应元素棒。
- 匠魂：蓝色史莱姆模型，制造蓝色、紫色或岩浆史莱姆球。
- 血魔法：四种腐化生物共用恶魔模型，制造含 50 意志的恶魔意志或五类意志结晶。
- 所有模型支持框架绑定、击杀成长、模拟室、战利品制造机、数据中心、JEI；补充混沌守卫、蓝色史莱姆和腐化恶魔的中英文介绍。全部安装后默认生物模型由 29 个增至 35 个。

联动 Mod 及其前置均独立安装；未安装对应 Mod 时跳过模型。龙研 / 热力在本基线使用 **CodeChickenLib CRE 3.3.5**。旧 CCL `3.2.3.358` 在 Java 25 客户端会崩溃，CRE `3.3.10` 要求更高加载器，均不用于本次验收。

混沌守卫模型一次击杀达到基础；推理需要持续供给 **32,768 FE/t**。数据中心每个守卫模型为 **49,152 FE/t**。

修复混沌守卫和末影龙的多部位实体绑定：点击头、身体、尾部或翅膀均识别为对应主体模型；调整混沌守卫预览比例，避免遮住信息文字。

## 安装

替换旧 HNN jar，安装 `hostile-neural-networks-legacy-6.5.1-cleanroom.2.jar`。`-sources.jar` 为开发源码。Ponder 的 Loader ID 继续使用 `ponder-legacy`，资源命名空间为 `ponder`。

模型 ID、产物数量、依赖文件与验收范围详见 [联动说明](https://github.com/mcyudream/hostile-neural-networks-legacy/blob/v6.5.1-cleanroom.2/docs/INTEGRATIONS.md) 和 [正式基线验收](https://github.com/mcyudream/hostile-neural-networks-legacy/blob/v6.5.1-cleanroom.2/LEGACY-VERIFICATION.md)。
