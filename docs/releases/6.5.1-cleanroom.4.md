# Hostile Neural Networks Legacy 6.5.1-cleanroom.4

目标：Minecraft 1.12.2 / Cleanroom 0.4.0 正式版 / Java 25。

## 修复

- 修复终极模拟室在小窗口或较大 GUI 比例下背包格子与点击位置错开的问题。
- 统一库存点击、释放、拖动物品和侧栏按钮的事件坐标处理，避免重复缩放。
- 扩展机器背包使用 Extra HNN 原始贴图，与机器面板保持一致。
- 修复小窗口下 JEI 列表继承机器界面缩放、压到面板与侧栏按钮的问题。
- 补充满背包的普通 / 小窗口实机截图，以及通过实际客户端容器协议进行的取出、放回和服务器同步检查。

## 外部机器控制 API

- 增加不依赖 AE2 的通用外部机器控制接口，供独立 HNN AE2S / Supergiant 附属使用。
- 控制期间保护机器库存与产物选择，保留真实 FE 消耗、生产进度、序列化和任务释放行为。
- 使用方式见 [API 说明](https://github.com/mcyudream/hostile-neural-networks-legacy/blob/v6.5.1-cleanroom.4/docs/AUTOMATION-API.md)。
