# Hostile Neural Networks Legacy 6.5.1-cleanroom.3

目标：Minecraft 1.12.2 / Cleanroom 0.4.0 正式版 / Java 25。

## 新增

- 将 Extra HNN 2.2.5 的模型融合室、模型模拟器、完美模型和框架、三种升级卡、设定卡直接并入。
- 增加 V1～V4 终极模拟室与终极战利品制造器，支持四目标生产、批次制造和 36 槽输出。
- 完美模型接入学习器、HUD、击杀成长、训练、保存和自动化。
- 新增可选血魔法数字化苦难之井及祭坛链接器，支持催化剂、献祭符文增幅和直接供给 LP。
- 使用 Extra HNN 原始 GUI、方块和物品资源，适配 1.12.2 槽位、中文、小屏缩放和 JEI 避让。
- 新增合成配方、JEI 说明及 Ponder 融合 / 祭坛分步演示。
- 保留 Extra HNN MIT 许可证和固定上游记录。

完整参数和 1.12 配方替代见 [扩展玩法说明](https://github.com/mcyudream/hostile-neural-networks-legacy/blob/v6.5.1-cleanroom.3/docs/EXPANSION.md)。
运行验收、安装包散列见 [LEGACY-VERIFICATION.md](https://github.com/mcyudream/hostile-neural-networks-legacy/blob/v6.5.1-cleanroom.3/LEGACY-VERIFICATION.md)。

## 运行验收与安装

正式 Cleanroom 0.4.0 上四组生产包验收通过：客户端 119 / 310 项，专服 101 / 213 项。
安装包 SHA-256：`0f0c8d53f22e9f12594f870e61a0faf2be0ffaf34453ab1ccf89a0ec97dfdcd7`。

安装生产包 `hostile-neural-networks-legacy-6.5.1-cleanroom.3.jar`；源码包不用于游戏安装。
Ponder 为可选独立前置，Mod ID 为 `ponder-legacy`。血魔法功能需另装 Blood Magic 及其前置。
保留上一版的可选依赖验证边界：匠魂 2.13.0.183 在本环境存在部分工具模型加载警告；HNN 数据模型、机器联动和新增物品已通过检查，详见验收记录。
