# Extra HNN 与数字化苦难之井

从 `6.5.1-cleanroom.3` 开始，将 [Extra Hostile Neural Networks](https://www.mcmod.cn/class/22092.html)
的玩法直接并入 HNN Legacy。无需另装 Extra HNN；所有新增注册 ID 均使用 `hostilenetworks`。

## 完美模型流程

1. 准备四个达到 **自我意识** 的普通模型，允许相同目标重复。
2. 模型融合室上方四槽放入模型，右侧放入一个完美模型框架。
3. 提供 `25,000 FE/t`，持续 `500 ticks`。完成时消耗五个输入，中央输出一个完美模型。
4. 完美模型保留四个有序目标，使用独立的五级进度：自主、智能、适应、综合、全能。
5. 放入深度学习器击杀对应目标，或使用模型模拟器训练；一次匹配击杀只增长一次，重复目标不会重复计分。
6. 放入终极模拟室，使用四个目标都接受的公共模拟材料进行生产。

| 等级 | 累计数据 | 每次匹配击杀 / 模拟数据 | 基础预测成功率 |
| --- | ---: | ---: | ---: |
| 自主 | 0 | 20 | 10% |
| 智能 | 1,500 | 30 | 30% |
| 适应 | 4,500 | 50 | 50% |
| 综合 | 10,750 | 75 | 74% |
| 全能 | 22,375 | 0 | 100% |

开启原有连续准确率配置时，等级之间按累计数据插值。模型仍保留四个目标及其顺序，预测和基础产物均按四个目标分别生成。

## 终极机器 V1～V4

| 档位 | FE 容量 | 模拟时长 | 每次原料 | 每目标产量倍数 | 制造时长 | 制造 FE/t | 每批预测上限 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| V1 | 10,000,000 | 250 ticks | 4 | 1 | 50 ticks | 4,096 | 4 |
| V2 | 50,000,000 | 200 ticks | 16 | 4 | 40 ticks | 16,384 | 16 |
| V3 | 100,000,000 | 150 ticks | 32 | 8 | 30 ticks | 65,536 | 32 |
| V4 | 200,000,000 | 100 ticks | 64 | 16 | 20 ticks | 262,144 | 64 |

终极模拟室每刻 FE 为四个目标原始模拟耗能之和，所有目标共享一次准确率判定。
八个输出槽提前检查最坏产量；原料只在完成时消耗。模型、原料不匹配或输出堵塞时暂停。
右侧按钮控制红石模式和模型自动抽取；关闭抽取时，管道只能抽出产物。

终极战利品制造器拥有 36 个输出槽，支持固定产物与轮询队列。
输入不足或剩余输出空间较小时按可处理数量缩小批次；一个批次结束后队列前进一次。
产物的元数据和 NBT 保留，超出单槽的产量拆分存储。

## 模型模拟器与升级卡

不需要材料，不产出战利品，支持普通及完美模型。默认容量 `100,000,000 FE`，
每周期 `100 ticks`、`100,000 FE/t`。普通模型默认可从故障级训练。

| 升级卡 | 默认作用 |
| --- | --- |
| 速度 | 周期缩短 50%，每刻 FE 翻倍 |
| 数据 | 每周期数据翻倍；本周期最多训练到下一级门槛 |
| 等级 | 每周期直接提升一级，每刻 FE 改为 10,000,000 |

拥有两个升级槽，可组合不同卡；同类重复卡不会叠加。速度卡会继续乘算等级卡的耗电。
管道保留尚未训练完成的模型，仅在满级后允许抽取。
最低等级、训练黑名单、速度和数据倍率、耗能及时长均可通过 `hostilenetworks.cfg` 调整。

## 设定卡

- 潜行右击机器复制，直接右击兼容机器粘贴，潜行对空右击清除。
- 复制红石、模拟模式、模型抽取选项、固定选择与队列。
- 普通 / 终极制造器之间可互相粘贴产物选择。
- 模型槽复制目标信息；粘贴时从玩家背包转移真实匹配模型，保留该模型自身的数据和 NBT。
- 正在进行的模拟周期不能通过粘贴复用进度；卡片不存储电量、产物或运行进度。

## 血魔法：数字化苦难之井

仅安装 Blood Magic 时启用机器、祭坛链接器和相应配方；原有腐化恶魔模型继续提供意志产物。

1. 用祭坛链接器点击血之祭坛记录坐标，再点击同维度 `32` 格内的数字井。
2. 上侧槽放入基础级或更高的**普通数据模型**，任意侧输入 FE。
3. 默认每周期 `60 ticks`，每刻 `128 FE`；基础 / 进阶 / 高级 / 自我意识模型分别产生 `50 / 75 / 150 / 300 LP`。
4. 下侧槽可选放入通用预测：主世界 `2.2×`、下界 `2.4×`、末地 `2.7×`、暮色 `2.5×`，每个催化剂可用十个完成周期。
5. 最终 LP 继续乘算祭坛自身的献祭符文倍率，并直接进入真实祭坛主储槽。

祭坛必须保持加载。机器不强制加载区块；满坛、祭坛消失或红石暂停时停止新周期。
绑定、剩余催化次数、周期进度和待交付 LP 均写入存档，重载不重复生成 LP。
容量、耗能、周期、距离、等级产量和催化倍率均可配置。

## 1.12.2 配方替代与资源

Extra HNN 的十五个合成配方保留原有形状和升级链，替换 1.12.2 不存在的材料：

| 原材料 | 本移植 |
| --- | --- |
| 下界合金碎片 | 石英 |
| 下界合金锭 | 下界之星 |
| 下界合金块 | 钻石块 |
| 下界合金剑 | 钻石剑 |
| 铜锭 | 铁锭 |

数字井使用模拟室、预测矩阵、模型框架、充能石板和红石合成；祭坛链接器使用空白石板、红石和金锭。
JEI 可查看全部合成、机器说明与模拟 / 制造产物。可选 Ponder 增加完整的融合生产与祭坛供能流程。

GUI 采用 Extra HNN 原始 MIT 资源和逻辑坐标，并接入原有小屏缩放、鼠标坐标转换和 JEI 避让。
数字井采用 HNN 界面风格及 Minecraft 原生资源。
